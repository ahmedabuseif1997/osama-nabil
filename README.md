# Osama Nabil — Portfolio

Static portfolio site (HTML/CSS/JS, no framework, no build step to run it), English + Arabic (RTL),
pre-rendered for search engines and LLM crawlers, with a project-brief conversion funnel.

## Structure

| Path | Purpose |
| --- | --- |
| `index.html`, `style.css`, `app.js` | The site (the former "Design 6 — Kinetic": isometric image wall, kinetic type, 3D coverflow, scroll-read text) |
| `assets/js/data.js` | Projects in client-list order: titles/descriptions (EN/AR), categories, country, images `[file, w, h, edge colour]`; `"client": false` keeps a project out of the client strip |
| `assets/js/strings.js` | All UI copy EN/AR (pure JSON after `=`, read by `tools/prerender.py`) |
| `assets/js/core.js` | Profile (contact links, Web3Forms key, years, markets), language toggle, lightbox, reveal, count-up |
| `assets/js/funnel.js` | 3-step brief (send via WhatsApp or email), sticky CTA, clients strip |
| `assets/js/motion.js` | Smoothed scroll loop, section progress, tilt, magnetic buttons, cursor, word split |
| `assets/css/*.css` | Shared lightbox, funnel (brief, FAQ, contact bar) and motion styles, themed with `--f-*` variables |
| `assets/work/<slug>/NN.webp` | Project images; `01.webp` is the cover |
| `assets/img/` | Portrait (share image), avatar, favicon, brand icons (Simple Icons, CC0) |
| `tools/prerender.py` | SEO / LLM-SEO pre-render (see below) |
| `robots.txt`, `sitemap.xml`, `llms.txt` | Generated by `tools/prerender.py` |
| `vercel.json`, `.vercelignore` | Vercel config (headers, caching, `osamanabil.com` → `www` redirect) |

## SEO and LLM SEO

`python3 tools/prerender.py` (run after any content change) writes into every page that has the markers:

- The full English copy into the HTML (every `data-i18n` element, plus static project and service lists),
  so crawlers that do not run JavaScript — including most AI crawlers — read the whole page.
- The `<head>` block: title, description, canonical, robots, Open Graph, Twitter card and JSON-LD
  (`WebSite`, `ProfilePage`, `Person`, `ProfessionalService` with offer catalog, `FAQPage`, `ItemList` of `CreativeWork`).
- Shared funnel partials: clients strip, mid-page CTA, FAQ, brief form, sticky CTA.
- `robots.txt` (explicitly allows GPTBot, ClaudeBot, PerplexityBot, Google-Extended and others),
  `sitemap.xml` and `llms.txt` (plain-language summary for LLMs).

Absolute URLs use `SITE_URL` (default `https://ahmedabuseif1997.github.io/osama-nabil/`).
For a custom domain: `SITE_URL=https://example.com/ python3 tools/prerender.py`.

## Conversion funnel (client project inquiries)

- Hero: "Start your project" first, "View work" second, proof line (8+ years · 20 brands · 5 countries · 247 designs).
- Clients strip after the hero; mid-page CTA after the work; FAQ; contact bar with WhatsApp, Instagram, Behance, Facebook, Gmail.
- 3-step brief (services → timing / budget + currency → contact). Two ways to send:
  - **Send via WhatsApp** opens a chat to +20 100 560 6850 with the brief written in; a copy is emailed in the background.
  - **Send by email** delivers the brief to `osamanabil419700@gmail.com` through Web3Forms (no email app needed).
  - Without a Web3Forms key, or if the service fails, email falls back to opening the visitor's email app with the brief,
    plus a copy button — no brief is lost.
- Sticky "Start your project" bar after the hero, hidden while the brief is on screen.

**Web3Forms key:** go to web3forms.com, enter `osamanabil419700@gmail.com`, copy the access key from the email, and
put it in `assets/js/core.js` → `profile.formKey` (set; Web3Forms keys are public by design and only allow sending to the registered inbox).

## Editing

- Copy / translations: `assets/js/strings.js`.
- Contact details (email, WhatsApp, Instagram, Behance, Facebook), years of experience and markets (Egypt, Saudi Arabia, UAE, Oman, Qatar — in display order): `assets/js/core.js` → `profile`, mirrored in `tools/prerender.py` (`EMAIL`, `PHONE`, `SOCIAL`, `COUNTRIES`).
- Client list order = project order in `assets/js/data.js`; `"client": false` keeps a project out of the client strip (Green Motion, Arabic Typography).
- Brand icons in `assets/img/icons/` are from Simple Icons (CC0).
- Add a project: images in `assets/work/<slug>/` (cover = `01.webp`) and an entry in `assets/js/data.js`.
- `?lang=ar` forces Arabic; the choice is remembered per browser.
- Then run `python3 tools/prerender.py`.

## Deploy (Vercel)

Static site, no build step. `vercel.json` sets clean URLs, security headers, asset caching and the bare-domain → `www` redirect; `.vercelignore` keeps `tools/` and this README out of the deploy.

1. vercel.com → **Add New… → Project** → import `ahmedabuseif1997/osama-nabil`.
2. Framework preset **Other**, leave Build Command and Output Directory empty → **Deploy**.
3. Every push gets its own preview URL; `main` is production.
4. Project → **Settings → Domains** → add the domains below and set the DNS records Vercel shows.
5. Domain: add both `www.osamanabil.com` (primary) and `osamanabil.com`; `vercel.json` redirects the bare domain to `www`.
   All SEO URLs already use `https://www.osamanabil.com/` (`tools/prerender.py` → `SITE_URL`).
